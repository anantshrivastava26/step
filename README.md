# step

A collection of small Java exercises and algorithm practice solutions used for learning and interview preparation.

**Quick Start**

- **Requirements:** Java 8 or newer.
- **Compile all sources:** `javac *.java`
- **Run the main program:** `java Main` (or run any specific class with a `main` method)
- **Run with sample input:** `java Main < input.txt`

**Repository Structure**

- **Description:** Several standalone Java programs solving array, matrix, and algorithmic problems.
- **Notable files:**
	- [3Sum.java](3Sum.java) — 3-sum / triplet-sum problem implementation
	- [rotateMatrix90.java](rotateMatrix90.java) — rotate matrix by 90 degrees
	- [Transpose.java](Transpose.java) — matrix transpose helpers
	- [diagonalSum.java](diagonalSum.java) — compute diagonal sums
	- [temperature.java](temperature.java) — sample problem (temperature-related logic)
	- [TransportationCostMatrix.java](TransportationCostMatrix.java) — cost matrix problem
	- [Main.java](Main.java) — example driver (if present, used as entrypoint)
	- [input.txt](input.txt) — sample input used by some programs

**How to Use**

1. Open a terminal in this folder.
2. Compile sources: `javac *.java`.
3. Run a program: `java ClassName` (replace `ClassName` with the class you want to run, e.g., `Main`).
4. Redirect input from `input.txt` if needed: `java ClassName < input.txt`.

**Contributing**

- Add new problem solutions as separate `.java` files.
- Ensure each file with an entrypoint contains a `public static void main(String[] args)` for easy testing.
